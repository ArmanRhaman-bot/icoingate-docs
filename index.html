DEVELOPER API

iCoinGate API

Integrate iCoinGate wallet transfers into your Telegram bot or application.

Open Wallet Contact Support
AUTHENTICATION

API Credentials

Every request must include your iCoinGate API Key and API Secret.

api_key

Your unique developer API Key.

api_secret

Your private API Secret used to authenticate requests.

Keep your credentials private. Never publish your API Secret in public repositories or client-side applications.
WITHDRAWAL

Withdrawal API

Transfer supported cryptocurrency from your iCoinGate developer balance to another iCoinGate user.

POST YOUR_WEBHOOK_URL

Your personal Webhook URL is generated automatically when you create your API.

REQUEST

Request Body

Send the following JSON body to your generated iCoinGate Webhook URL.

JSON 
{
  "api_key": "YOUR_API_KEY",
  "api_secret": "YOUR_API_SECRET",
  "coin": "USDT",
  "amount": 0.1,
  "to_user_id": "6284575410"
}
PARAMETERS

Request Parameters

Parameter Type Description
api_key String Your developer API Key.
api_secret String Your private API Secret.
coin String Cryptocurrency symbol, e.g. USDT.
amount Number Amount of cryptocurrency to transfer.
to_user_id String Telegram ID of the recipient.
RESPONSE

Successful Response

A successful request returns transfer information including the remaining developer balance.

JSON 
{
  "status": "success",
  "message": "Withdrawal completed successfully",
  "app_name": "Your App",
  "coin": "USDT",
  "amount": 0.1,
  "to_user_id": "6284575410",
  "remaining_balance": 99.9,
  "transfer_id": "XXXXXXXXXXXX"
}
ERRORS

Error Responses

Invalid API Key The provided API Key is invalid.
Invalid API Secret The provided API Secret is invalid.
Insufficient balance The developer does not have enough balance for the requested transfer.
Invalid amount Amount must be greater than zero.
Unsupported coin The requested cryptocurrency is not supported.
Missing receiver user ID A recipient Telegram ID is required.
INTEGRATION

Developer Example

Example of sending a withdrawal request from a Bots.Business bot.

View Bots.Business example
BJS 
const API_KEY =
  "YOUR_API_KEY";

const API_SECRET =
  "YOUR_API_SECRET";

const API_URL =
  "YOUR_WEBHOOK_URL";

HTTP.post({
  url: API_URL,

  body: JSON.stringify({
    api_key: API_KEY,
    api_secret: API_SECRET,
    coin: "USDT",
    amount: 0.1,
    to_user_id: "6284575410"
  }),

  headers: {
    "Content-Type": "application/json"
  }
});
SECURITY

Security

Keep your API Key, API Secret and Webhook URL private.

Never store credentials inside public GitHub repositories or client-side applications.

If your credentials are compromised, regenerate your API credentials immediately.
