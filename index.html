BOT INTEGRATION

/withdraw Command Example

A ready-to-use example showing how to wire up a /withdraw command in your Telegram bot. It parses the amount and recipient from the message, checks your balance, then calls the iCoinGate withdrawal endpoint.

1

Parse the command

Reads the amount and Telegram ID from /withdraw 8994226373 30.

2

Validate

Checks the format, your balance, and blocks self-transfers.

3

Call the API

Sends the withdrawal to iCoinGate with your API key & secret.

4

Handle the result

Routes to a success or error command based on the response.

JavaScript 
let args = (String(message || "").trim()).split(/\s+/);

if (args.length < 3) {
  return Api.sendMessage({
    chat_id: chat.chatid,
    text: "❌ <b>Usage:</b>\n<code>/withdraw 8994226373 30</code>\n(Any order works)",
    parse_mode: "HTML"
  });
}

let amount = parseFloat(args.find(a => /^\d+(\.\d+)?$/.test(a) && parseFloat(a) > 0));
let toUserId = args.find(a => /^\d{5,15}$/.test(a));

if (!amount || !toUserId) {
  return Api.sendMessage({
    chat_id: chat.chatid,
    text: "❌ <b>Invalid format</b>\nDetect failed. Use: /withdraw 8994226373 30",
    parse_mode: "HTML"
  });
}

const API_KEY = "API_KEY";
const API_SECRET = "SECRET_KEY";
const API_URL = "WEBHOOK_URL";

const coin = "USDT";
let developerBalance = parseFloat(Libs.ResourcesLib.userRes(coin).value()) || 0;

if (amount > developerBalance) {
  return Api.sendMessage({
    chat_id: chat.chatid,
    text: `❌ <b>Insufficient ${coin} balance</b>\nAvailable: <code>${developerBalance} ${coin}</code>`,
    parse_mode: "HTML"
  });
}

if (String(user.telegramid) === String(toUserId)) {
  return Api.sendMessage({
    chat_id: chat.chatid,
    text: "❌ You cannot withdraw to your own account.",
    parse_mode: "HTML"
  });
}

HTTP.post({
  url: API_URL,
  body: JSON.stringify({ api_key: API_KEY, api_secret: API_SECRET, coin, amount, to_user_id: toUserId }),
  headers: { "Content-Type": "application/json" },
  success: `/withdraw_success ${amount} ${coin} ${toUserId}`,
  error: `/withdraw_error ${amount} ${coin} ${toUserId}`
});
⚠ Before you deploy

Replace API_KEY, SECRET_KEY and WEBHOOK_URL with your real iCoinGate credentials and endpoint. Keep them out of public repositories or client-side code.
