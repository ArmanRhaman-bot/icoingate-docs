AUTHENTICATION

API Credentials

Every request must include your iCoinGate API Key and API Secret.

API Key YOUR_API_KEY
API Secret YOUR_API_SECRET
Security

Never share your API Secret publicly. Store your credentials securely.

TRANSFERS

Developer Withdrawal

Transfer cryptocurrency from the developer's iCoinGate wallet to another Telegram user.

POST /api_withdraw

Parameters

Parameter Type Required
api_key String Yes
api_secret String Yes
coin String Yes
amount Number Yes
to_user_id Telegram ID Yes
REQUEST

Example Request

A simple example of an iCoinGate withdrawal request.

JSON 
{
  "api_key": "YOUR_API_KEY",
  "api_secret": "YOUR_API_SECRET",
  "coin": "USDT",
  "amount": 0.1,
  "to_user_id": "6284575410"
}
RESPONSE

Successful Response

When the transfer is completed successfully, the API returns the transfer details.

JSON 
{
  "status": "success",
  "message": "Withdrawal completed successfully",
  "app_name": "Your App",
  "coin": "USDT",
  "amount": 0.1,
  "to_user_id": "6284575410",
  "remaining_balance": 99.9,
  "transfer_id": "ABC123XYZ",
  "timestamp": "2026-08-17T12:00:00Z"
}
